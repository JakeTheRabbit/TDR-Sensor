Manual readings
Set the sensor's Substrate Profile before recording. Changing that profile clears its saved references.

Record the settled wet reference

Wet uniformly through the normal delivery path, then let free drainage settle. On a planted substrate, use a normal wet irrigation plateau.

A wet reference sets an index of 100. It does not establish 100% VWC or a calibrated dryback percentage.

Define the sample on the scale

Use a spare, unplanted sample of the same medium, packing and geometry. Keep its sensor position fixed between measurements.

Include the same container, sleeve, support and probe in every weighing. Air-dry medium can still contain water; use a defensible dry mass.

Record A and B, then check a separate intermediate moisture level C.
Why three points?

A and B establish an offset and gain around the probe's generic soilless response. They must differ by at least 100 RAW counts and 10 VWC percentage points. C must lie strictly inside the middle 80% of their RAW interval. Use the same physical sample; don't calculate C from the fitted curve.

The sensor receives VWC rounded to its 0.1% input step. The check below uses that same rounding.

Apply on the sensor

    1. Fill in your own secrets.yaml locally. Generate a new API encryption key in ESPHome.
    2. Validate and build with ESPHome 2026.8.2, then install the generated device YAML.
    3. Open the device's web page. Press Apply wizard setup. This selects the medium and starts a fresh capture window.
    4. Complete calibration on the device using the calibration guide.
    5. Check saved values, turn Calibration mode off and wait at least ten seconds before disconnecting power.
